# 🧮 Hiyohi Budget App
シンプル費用のウェブのアプリです。収入金額と支出金額を追加する際に自動に計算出来ます。<br>

# 💻 言語
<ul>
  <li>Javascrip</li>
  <li>CSS</li>
  <li>HTML</li>
</ul>

# 📜 ソフト
<ul>
  <li>Visual Studio Code</li>
</ul>

# ⚙️ 内容部分
<ul>
  <li>収入や支出のリストを作り</li>
  <li>結果をリセットの可能</li>
</ul>

# 🧠 考え
人生の費用することを難しいのでこのアプリで自分の貯金や収入や支出を覚えるようにシンプル便利なアプリを作りました。デスクトップの向けに作られたけどスマートフォンでも可能性あります。
